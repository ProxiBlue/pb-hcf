## Implementation Notes
- `scripts/rector-check.sh`: deterministic layer only — scoped `git diff --name-only` filter
  (excludes `generated/` and `Test/*/_files/` fixtures), degrades to `exit 0` + install note
  when `vendor/bin/rector` or `rector.php` is absent, `exit 1` + rector's own diff output when
  a dry-run proposes transforms. shellcheck-clean (docker `koalaman/shellcheck`) and `bash -n`
  clean. Functionally smoke-tested end to end in a scratch git repo (degrade path, no-changed-
  files path, exit-1-with-diff path, and generated/fixture exclusion), not just grep-verified.
- `agents/pre-commit-adversarial-pass.md`: new `Step 4 — rector-diff judgment` runs the script
  and judges only the contested remainder rector.php's `withSkip()` doesn't already cover
  (plugin/observer/di.xml-reachable signature changes, XML-wired dead-code, ObjectManager/mock
  constructor risk) — explicitly framed as NOT re-litigating generic style rules already
  resolved by the deterministic skip list. Old Step 4 (verdict) renumbered to Step 5; PASS
  summary and DEFER example both extended with a rector-diff line.
- `skills/wire/SKILL.md`: one new bullet in the step-2 CLAUDE.md fence template pointing at
  `@rector.php` (project root, per `templates/rector/README.md`'s install instructions).
  Deviated from the task context's literal `.claude/rector.php` wording — every other
  authoritative source in the repo (README, task 010, `skills/modernization-sweep/SKILL.md`,
  and this task's own agent edit) uses the project-root path, and nothing in the plan installs
  `rector.php` under `.claude/`, so a `.claude/rector.php` pointer would be broken/misleading
  for a real user. Confirmed tasks 002/006/008's sections (bricklayer probe row + wires.json
  entry, constitution-install fence, bugsink probe row + wires.json entry) untouched, and the
  `pb-hcf:start`/`pb-hcf:end` fence markers remain a single non-duplicated pair.
